Gruppieren von zusammengehörigen Daten (Objektorientierte Programmierung)

Hierbei handelt es sich um nichts das zu pygame gehört, sondern um eine ganz allgemein nüzliche Technik. Nämlich objektorientierte Programmierung. Dies soll aber keine detaillierte Einführung in objektorientierte Programmierung sein, sondern nur anhand eines Beispiels einen sehr kurzen Überblick verschaffen. Dieser sollte ausreichen damit du Objekte verwenden kannst, auch wenn du nicht alles im Detail verstehst.

Das Beispiel: Spielkarten! Du hast ein Deck von Spielkarten und jede davon hat eine Farbe und einen Wert. Möglicherweise benötigt deine Karte noch weitere Informationen, die du gerne dazu speichern würdest. Wie kannst du das also in Python abbilden? Viele Variablen erstellen ist unschön und wird sehr unübersichtlich. Speicherst du das in einer Liste ist das zwar schöner, aber du hast dann immer noch mehrere Listen (eine für die Farbe, eine für die Katenwerte, ...). Eine gute Lösung ist objektorientierte Programmierung. Ein Objekt kannst du dir dabei als eine Art Container vorstellen: Du kannst Kartenfarbe und -wert hineinlegen und musst dir nur den Container merken (also eine Variable anstatt mehreren pro Karte). Genauso kannst du die Container in einer Liste speichern und hast so nur eine Liste in der alle Informationen zu allen Karten zu finden sind (z.B. alle Karten die ein Spieler in der Hand hält).

In unserem Beispiel soll jede Spielkarte eine Farbe (Herz, Pik, Karo oder Kreuz), einen Kartenwert (1-13) und eine weitere Information (einen Kartentext) haben. Das Deck könnte also eine Karte "Pik 7 mit Text 'Viel-Pik'" und eine Karte "Herz 2 mit Text 'Herz an Herz'" enthalten.

Um das zu programmieren machst du eine Klasse "Spielkarte. Diese enthält einen sogenannten Konstruktor (das __init__(...)). Dieser wird aufgerufen wenn du eine neue Karte definierst. Darum gibst du ihm auch alle Informationen mit die er benötigt um eine Karte zu definieren: Die Farbe (f), den Wert (w) und den Kartentext (t).


class Spielkarte:
    def __init__(self, f, w, t):

In diesem Konstruktor drin werden diese Daten dann gespeichert in 'self'. Das self muss beim definieren zwar immer dort stehen, kannst du beim Aufrufen aber ignorieren.


class Spielkarte:
    def __init__(self, f, w, t):
        self.farbe = f
        self.wert = w
        self.text = t

Damit ist die Vorlage für eine Spielkarte schon fast fertig programmiert. Als kleine Erweiterung kannst du Spielkartenfarben noch etwas schöner ablegen als einfach eine Zahl oder einen Text zu verwenden. Das geht mit einer Enum (kurz für Aufzählung - enumeration). Die Werte einer sochen Enum kann man ähnlich wie Variablen verwenden.


from enum import Enum
Farben = Enum('Farben', [('Herz', 1), ('Pik', 2), ('Karo', 3), ('Kreuz', 4)])

Dieser Codeausschnitt definiert ein Enum mit dem Namen "Farben" und den Werten "Herz", "Pik", "Karo" und "Kreuz" (die zusätzlich, als alternativwerte, auch noch durchnummeriert wurden). Damit kannst du dann im Code mit Farben.Herz darauf zugreifen und z.B. testen ob dies deiner Kartenfarbe entspricht.

Hier nochmal der komplette Code inklusive einem Beispiel: Es werden zwei Spielkarten angelegt, beide angeschaut und geprüft ob deren Wert grösser als drei ist. Falls das zutrifft wird etwas anderes ausgegeben als wenn nicht.


from enum import Enum

Farben = Enum('Farben', [('Herz', 1), ('Pik', 2), ('Karo', 3), ('Kreuz', 4)])

class Spielkarte:    
    def __init__(self, f, w, t):
        self.farbe = f
        self.wert = w
        self.text = t

karten = [ Spielkarte(Farben.Pik, 7, "Viel-Pik"), Spielkarte(Farben.Pik, 2, "Herz an Herz")]
for k in karten:
    if k.wert > 3:
        print(k.farbe, k.wert)
    else:
        print(k.text)
